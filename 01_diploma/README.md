# Дипломный проект: Оформление спецификации требований на разработку ПО

**Контекст:** Выпускная работа по программе «Системный аналитик: расширенный курс» (Нетология).

**Задача:** Разработать спецификацию требований для программного обеспечения в соответствии с IEEE 830.

**Моя роль:** Системный аналитик — полный цикл: интервью, анализ, моделирование, документирование.

**Инструменты:** PlantUML, Swagger, Markdown, draw.io.

---

## 📌 Что сделано

- Провела интервью с заказчиком, составила таблицу сценариев.
- Построила диаграмму Use Case (с исходником на PlantUML).
- Построила диаграмму классов с таблицей сущностей.
- Написала функциональные и нефункциональные требования.
- Оформила Swagger-документацию для API.
- Составила трассировку требований.
