1\. Введение
------------

### 1.1 Назначение

Настоящая спецификация требований к программному обеспечению описывает функциональные и нефункциональные требования к выпуску 1.0 мобильного приложения «Слово дня» (далее — Система).

Документ предназначен для команды разработчиков, которая будет реализовывать и проверять корректность работы системы. Кроме специально обозначенных случаев, все указанные здесь требования имеют высокий приоритет и приписаны к выпуску 1.0.

### 1.2 Соглашения, принятые в документах

В настоящей спецификации используются следующие типографские обозначения:

\- Жирный шрифт выделяет названия сущностей, атрибутов и ключевые термины.

\- \`Моноширинный шрифт\` используется для имён полей, идентификаторов требований (FR, NFR) и эндпоинтов API.

\- Требования имеют уникальные идентификаторы: FR-XXX — функциональные, NFR-XXX — нефункциональные.

### 1.3 Границы проекта

Мобильное приложение «Слово дня» позволит пользователям (ученикам языковой школы) запоминать новые иностранные слова с помощью регулярных уведомлений и ведения персонального словаря. Система автоматизирует процесс запоминания слов, заменяет бумажные глоссарии и повышает удержание учеников через регулярные напоминания.

Приложение заменяет текущий ручной процесс ведения словарей в тетрадях, которые не всегда под рукой у учеников.

Детальное описание продукта приведено в документах: интервью с заказчиком, сценарии использования (Use Cases), требования и модель данных.

Функции, запланированные в выпуске 1.0:

\- Авторизация через социальные сети (Google, Яндекс)

\- Выбор уровня владения языком (A1–B2) или прохождение входного теста

\- Получение push-уведомлений со словом дня (слово, транскрипция, перевод, пример использования)

\- Гибкая настройка уведомлений: время, дни недели, количество в день (до 3)

\- Просмотр полной карточки слова при клике на уведомление (все значения, кнопки «Выучил», «Напомнить позже», «Поделиться»)

\- Управление личным словарём: просмотр всех слов, добавление своих слов

\- Модерация пользовательских слов (только для слов, отмеченных для публикации)

\- Экспорт словаря (не входит в MVP, но добавлен по желанию)

Функции, выходящие за границы выпуска 1.0:

\- Поддержка нескольких языков для изучения (на старте — только английский)

\- Аудио-произношение слов

\- Восстановление словаря при смене устройства (сознательное бизнес-решение заказчика)
